# assets — 이미지

## 권하는 방법: 이미지 넣기 페이지

`start-presentation.bat` 실행 → 브라우저에서 **`/images.html`** 열기.
칸마다 무슨 사진이 들어가야 하는지, 어느 슬라이드에 쓰이는지가 적혀 있고,
사진을 **끌어다 놓으면** 알맞은 이름으로 저장됩니다. 파일명을 맞출 필요가 없습니다.

- 큰 사진은 브라우저에서 긴 변 2400px으로 줄여 올립니다 (각 칸의 `원본` 버튼으로 무시 가능)
- 교체하거나 뺀 사진은 지워지지 않고 `assets/_replaced/` 로 옮겨집니다
- 아이폰 HEIC는 브라우저가 표시하지 못하므로 거부됩니다 — JPEG로 내보내서 넣으세요
- 여러 장을 한꺼번에 떨어뜨리면 파일명이 일치하는 칸에 자동 배치됩니다

## 모아둔 이미지 — `_pool/`

아직 분류 안 한 사진은 `assets/_pool/` 에 넣어두세요. 탐색기에서 통째로 복사해 넣고
넣기 페이지에서 **새로고침**을 누르면 상단 트레이에 뜹니다. 거기서 썸네일을 칸으로
끌어다 놓거나, 클릭해서 고른 뒤 칸을 클릭하면 배치됩니다.

배치는 복사라서 원본은 `_pool/` 에 그대로 남습니다. 한 사진을 두 칸에 쓸 수 있습니다.

## 형식

- JPEG · PNG · WebP · GIF. **HEIC는 안 됩니다** (브라우저가 표시하지 못함).
- 확장자가 `.jpg`가 아니어도 그 이름으로 저장하면 브라우저가 알아서 읽습니다.
  넣기 페이지를 쓰면 자동으로 처리됩니다.
- 가로 2000–2400px 권장.
- S3 삼단(`alberti` / `cezanne` / `scan-lake`)과 S5 두 컷은 `object-fit: cover`로
  잘리므로 **가로형**으로 준비하세요.

형식으로 뽑아주시면 그 자리에 곡선을 그려 넣겠습니다. 6월 초 스파이크 이후 롱테일이
확인되면 이 발표에서 가장 강한 근거가 됩니다.
