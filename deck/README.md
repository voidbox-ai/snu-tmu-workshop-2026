# Presence Before Synchronization

SNU × TMU Annual Workshop · 20 slides · 13:50 planned · reveal.js 5.1.0

**인터넷 없이 동작합니다.** reveal.js와 Pretendard가 폴더에 함께 들어 있어서
발표장 와이파이가 죽어도, 발표용 노트북에 폰트가 안 깔려 있어도 상관없습니다.

씁니다. 실패 숫자 9 / 2 / 0은 색 없이 타이포로만 세웁니다. 색이 성공과 실패
양쪽을 가리키면 의미가 흐려지기 때문입니다. 이 색은 해당 배경색에서 대비·채도
검증을 통과한 값입니다.

> 비교용이며 **더 이상 갱신되지 않습니다** — 대본 편집은 `index.html`에만 반영됩니다.

## 폰트

슬라이드와 발표자 화면 **전부 Pretendard**입니다. `fonts/PretendardVariable.woff2`

## 발표자 화면에서 대본 고치기

`S`로 발표자 화면을 연 뒤, **NOTES 오른쪽의 `Edit` 버튼**을 누르면 그 슬라이드의 대본이
편집 가능한 텍스트로 바뀝니다. `Save`(또는 `Ctrl+S`)를 누르면 **`index.html`에 바로 기록**됩니다.
리허설하다 걸리는 문장을 그 자리에서 고치고 저장하면 됩니다.

**쓰는 법**

- 빈 줄 = 문단 나눔
- `[대괄호로 시작하는 문단]` = 연출 지시 (노란 세로줄로 표시되는 그 줄)
- `*기울임*`, `**굵게**`
- `Raw HTML` 버튼을 누르면 태그를 직접 편집할 수 있습니다
- `Esc` = 취소, `Ctrl+S` = 저장

**안전장치**

- 저장할 때마다 직전 `index.html`이 `.backups/` 에 시각별로 보관됩니다 (최근 40개)
- 편집 중에 슬라이드를 넘겨도 편집 내용은 사라지지 않고, 경고와 함께 유지됩니다.
  저장은 **편집을 시작한 슬라이드**에 기록되므로 엉뚱한 곳에 덮어쓸 일이 없습니다
- 텍스트 영역에서 타이핑해도 슬라이드는 넘어가지 않습니다
- 저장 즉시 발표 화면 쪽 `N` 노트에도 반영됩니다 (새로고침 불필요)

되돌리려면 `.backups/` 에서 원하는 시각의 파일을 `index.html`로 복사하면 됩니다.

## 키

| 키 | 기능 |
|---|---|
| `→` `←` `Space` `N` `P` | 슬라이드 이동 |
| **`S`** | **발표자 화면** — 현재/다음 슬라이드, 노트, 타이머 (로컬 서버 필요) |
| **`T`** | 페이스 표시줄 켜기/끄기 |
| **`I`** | 발표자 노트를 이 화면 오른쪽에 표시 (모니터 하나뿐일 때 / 리허설용) |
| `R` | 타이머 리셋 |
| `B` 또는 `.` | 화면 블랙아웃 |
| `ESC` | 슬라이드 전체 보기 |
| `?` | 단축키 안내 |

> 노트는 `N`이 아니라 **`I`** 입니다 — `N`은 reveal의 "다음 슬라이드"라서 겹칩니다.

## 화면 두 대로 발표할 때

`S`를 누르면 **메인 창은 관객용 스크린**이 되고, 발표자용 정보는 팝업 쪽으로 넘어갑니다.
그래서 발표자 화면이 연결되면 메인 창의 **페이스 표시줄·노트 패널·단축키 바가 자동으로 사라집니다.**
관객 화면에 남는 것은 슬라이드와 우측 하단 슬라이드 번호뿐입니다.

굳이 관객 화면에도 타이머를 띄우고 싶으면 그때 `T`를 누르면 되고,
발표자 화면을 닫으면 원래대로 돌아옵니다.

타이머는 **첫 슬라이드를 넘기는 순간 자동으로 시작**합니다.

## 이미지 넣기

`start-presentation.bat`으로 띄운 뒤 **<http://localhost:8000/images.html>** 을 열면
12개 칸이 나옵니다. 칸마다 어떤 사진이 들어가야 하는지, 어느 슬라이드에 쓰이는지가 적혀 있고,
**사진을 끌어다 놓기만 하면** 슬라이드가 찾는 이름으로 저장됩니다. 파일명을 맞출 필요 없습니다.

- 큰 사진은 브라우저에서 긴 변 2400px으로 줄여서 올립니다 (`원본` 버튼으로 무시 가능)
- 교체·삭제한 사진은 지워지지 않고 `assets/_replaced/` 로 옮겨집니다
- 아이폰 HEIC는 브라우저가 못 읽으므로 거부됩니다 — JPEG로 내보내 주세요

### 모아둔 이미지 (`assets/_pool/`)

아직 어느 칸에 넣을지 안 정한 사진들을 쌓아두는 곳입니다. **탐색기에서 이 폴더에
통째로 복사해 넣고**, 넣기 페이지에서 **새로고침**을 누르면 상단 트레이에 나타납니다.
페이지의 `파일 추가` 버튼이나 트레이에 끌어다 놓아도 됩니다.

트레이에서 칸으로 배치하는 방법 두 가지:

- 썸네일을 칸으로 **끌어다 놓기**
- 썸네일을 **클릭**해서 고른 뒤, 넣을 칸을 클릭 (`Esc`로 취소)

배치는 **복사**입니다 — 원본은 트레이에 남으므로 한 사진을 여러 칸에 쓸 수 있습니다.
표시할 수 없는 형식(HEIC 등)은 흐리게 나오고 배치가 막힙니다.

맨 위 상자에 여러 장을 한꺼번에 떨어뜨리면, **파일명이 칸 이름과 같은 것은 자동 배치**되고
나머지는 모아둔 이미지로 들어갑니다.

가장 급한 두 장은 `playground.jpg`(슬라이드 4·19)와 `munsan-overlay.jpg`(슬라이드 17)입니다.

## 파일

```
index.html              슬라이드 + 발표자 노트 (모든 내용이 여기 있음)
images.html             이미지 넣기 페이지 (끌어다 놓기)
assets/_pool/           미분류 사진 모아두는 곳 (탐색기로 복사해 넣어도 됨)
assets/_replaced/       교체·삭제된 사진 보관 (자동)
index-keynote.html      이전 검은 배경 버전 (동결, 비교용)
css/deck.css            테마
css/deck-keynote.css    이전 버전 테마 (동결)
fonts/                  Pretendard Variable (동봉 — 설치 불필요)
js/presenter.js         섹션 인덱스 바 · 타이머 · 노트 오버레이 · 이미지 슬롯
serve.py                로컬 서버 + 대본 저장 엔드포인트
start-presentation.bat  실행 (serve.py를 띄웁니다)
build-speaker-view.py   발표자 화면을 손봤을 때만 실행
reveal/                 reveal.js 5.1.0 (오프라인용 동봉)
assets/                 이미지 — 여기에 넣으세요
.backups/               대본 저장 시마다 자동 생성
```

> reveal.js는 발표자 화면 HTML을 `notes.js` 안에 문자열로 품고 있습니다.
> 그래서 `reveal/plugin/notes/speaker-view.html`을 고친 뒤에는
> `python build-speaker-view.py`를 한 번 돌려야 반영됩니다.
> 원본은 `notes.js.orig`로 남겨두었습니다.

내용을 고치려면 `index.html`만 열면 됩니다. 각 `<section>`에서 —
`data-sec`는 상단 인덱스 바의 구간, `data-title` / `data-sub`는 슬라이드 제목,
`data-dur`는 계획 시간(초), `<aside class="notes">` 안이 발표자 노트입니다.
제목 바는 `presenter.js`가 이 속성들로 자동 생성하므로 마크업을 손댈 필요가 없습니다.
